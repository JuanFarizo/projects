# Vision and Goals

## Vision
Build a **personal, local-first documentation intelligence system** (NotebookLM-like) focused on technical documentation, with strong grounding guarantees and full user control.

## Goals
- Single user-controlled source of truth
- High-quality querying of technical documentation
- Deterministic, snapshot-based knowledge states
- Zero or near-zero operational cost
- First-class integration with AI agents via MCP

## Explicit Scope
- Designed for engineers
- Optimized for technical documentation and notes
- prioritizes correctness over convenience
