# Minimal Structure Normalization

## Preserved Semantic Structure
- Document title
- Hierarchical headings (with levels)
- Logical sections
- Content blocks:
  - paragraphs
  - lists
  - fenced code blocks
- Ordering information
- Source references (file path or URL)

## Explicitly Discarded
- Navigation chrome
- Menus and sidebars
- Headers and footers
- Styling information
- JavaScript and dynamic elements

This structure represents **semantic intent**, not rendering fidelity.
